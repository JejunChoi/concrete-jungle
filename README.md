# Concrete Jungle of Patience

흙수저 땅바닥에서 출발해 30층 꼭대기 대리석 펜트하우스(건물주)까지 점프 하나로 올라가는 2D 웹 게임.
실수하면 아래층으로, 운 나쁘면 태초의 흙바닥까지 추락. 꼭대기까지 걸린 시간으로 랭킹.

## 파일

- `index.html` — 게임 페이지 (이 파일을 열면 바로 실행)
- `game.js` — 게임 전부 (그림도 소리도 코드로 그림, 따로 이미지 파일 없음)
- `config.js` — 랭킹 서버(Supabase) 주소와 키를 넣는 곳. 비워 두면 랭킹은 그 기기에만 저장
- `supabase.sql` — 랭킹 표를 만드는 SQL

## 디버그 모드

`game.js` 위쪽 `DEBUG_START_FLOOR` 숫자를 바꾸면 그 층에서 시작해요 (지금은 0 = 흙바닥부터). 0이 아니면 랭킹에 저장 안 해요.

## 모두가 함께 쓰는 랭킹 + 링크로 공유하기 (한 번만 하면 됨)

### 1. 랭킹 서버 만들기 (Supabase, 무료)

1. https://supabase.com 에 들어가 **Start your project** → GitHub 계정으로 가입
2. **New project** → 이름 아무거나(예: `concrete-jungle`), 데이터베이스 비밀번호 아무거나, 지역은 **Northeast Asia (Seoul)** → 만들기 (1~2분 걸림)
3. 왼쪽 메뉴 **SQL Editor** → `supabase.sql` 내용을 통째로 붙여 넣고 **Run**
4. 왼쪽 아래 **Project Settings → API** 에서 두 값을 복사
   - **Project URL** (예: `https://abcd1234.supabase.co`)
   - **anon public** 키 (긴 글자)
5. `config.js` 를 메모장으로 열어 두 값을 따옴표 안에 붙여 넣고 저장

> anon 키는 원래 웹페이지에 공개되는 키라 괜찮아요. **service_role** 키는 절대 넣지 마세요.

이제 `index.html` 을 더블클릭해서 열어도 모두의 랭킹이 보여요.

### 2. 인터넷에 올리기 (GitHub Pages, 무료)

1. https://github.com 로그인 → 오른쪽 위 **+ → New repository**
2. 이름 `concrete-jungle`, **Public** 선택 → **Create repository**
3. **uploading an existing file** 링크 → `index.html`, `game.js`, `config.js` 세 개를 끌어다 놓기 → **Commit changes**
4. 저장소 **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main / (root)** → **Save**
5. 1~2분 뒤 같은 화면 위쪽에 주소가 떠요: `https://(내 아이디).github.io/concrete-jungle/`

이 주소를 친구들에게 보내면 로그인 없이 누구나 플레이하고 같은 랭킹으로 경쟁할 수 있어요.
나중에 게임을 고치면 같은 방법으로 `game.js` 를 다시 올리면 돼요.
